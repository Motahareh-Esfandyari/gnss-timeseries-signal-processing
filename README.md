# Signal Processing of GNSS Coordinate Time Series

MATLAB code behind the manuscript "Efficiency of different signal processing
methods in extraction of signature characteristics of GNSS time series; Fine
detection of geophysical signals" by Motahareh Esfandyari-Kaloukan, Alireza
Amiri-Simkooei and Siavash Iran-Pour (under review; the full reference will
be added here after publication).

The study compares how well different signal processing methods extract the
signature characteristics of GNSS position time series: Fourier, short time
Fourier transform, continuous wavelets, singular spectrum analysis and
empirical mode decomposition with the Hilbert transform. Least squares
harmonic estimation was first applied to 730 GNSS stations to extract the
common features, which were then used to build a systematic 10 year
simulation. The detailed analysis uses daily vertical series of 10 NOTA
(UNAVCO) stations in California and Nevada over 15 years, split into two
groups by coastal proximity: stations within about 5 km of the coast and
stations up to 600 km inland. Frequencies related to climatic variations and
tidal loading (for example 24.7, 26.7, and the 128.79 to 158.56 cpy family)
are detected, and the Hilbert-Huang approach gives the clearest
time-frequency picture of them.

## Structure

```
1-preprocessing/      reading NOTA csv files, outlier removal, gap handling,
                      trend and harmonic fit, offset detection, and the
                      noise model machinery (LS-VCE for white plus flicker
                      noise, power law cofactor matrices)
2-lshe/               least squares harmonic estimation and the detection of
                      statistically significant frequencies per station
3-spectral-methods/   Fourier, STFT and wavelet analyses
4-ssa/                singular spectrum analysis, used both for trend
                      removal in preprocessing and as one of the compared
                      methods
5-emd-hilbert/        empirical mode decomposition and the Hilbert spectrum
6-simulation/         synthetic 10 year daily series with known trend,
                      harmonics, offsets and white plus flicker noise
7-figures/            plotting scripts used for the figures of the paper
data/                 one sample station file (P242, cwu igs14 solution)
```

## Workflow

For one station the order is roughly this. PreProcessing.m reads the csv,
removes outliers, fills short gaps and fits the functional model. The trend
is extracted with SSA (its first component) and removed, so the periodic
components stand out. The noise components are estimated with LSVCE_wf.m so
the later tests use a realistic covariance matrix. significant_frequency.m
runs LS-HE on the detrended series and stores the detected periods. Then the
spectral methods each get their turn on the same detrended series: fourier.m,
STFT.m, waveleteCPY.m, the SSA scripts in 4-ssa and the EMD plus Hilbert
scripts in 5-emd-hilbert. The intermediate results are passed between scripts
as mat files, so the scripts have to be run in this order the first time.

Station names are set at the top of each script. The mat files produced along
the way (GNSS_Analysis_*, impiricaal_mode_decomposition_* and so on) are not
in the repository, they are regenerated by running the chain.

## Data

One sample input file is included, P242.cwu.igs14.csv, so the whole chain can
be run end to end for that station. P242 sits close to the San Andreas fault
and is one of the coastal group stations of the paper. The other stations
(P199, P200, P213, P067 in the coastal group; P074, P075, P069, P572, TOIY in
the inland group) can be downloaded from the NOTA/UNAVCO data archive in the
same csv format.

## Requirements

MATLAB with the Signal Processing Toolbox (stft, hilbert), the Wavelet
Toolbox (cwt) and the Statistics Toolbox. EMD needs the emd function from
the Signal Processing Toolbox (R2018a or newer).
